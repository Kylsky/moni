# S2 账目检索验收（Issue #6）

2026-10-18；受保护接口 + 本地真实 D1，合成数据，无外部 AI 或报价依赖。

## 已完成

统一受限查询支持包含两端的日期范围、收入/支出/退款类型、类目、原币、任一所选标签、名称与备注关键词及分页。参数绑定，关键词按普通文字处理 `%`、`_` 和引号；不接受 SQL、数据集切换或任意查询字段。单次最多 100 条、默认 20 条；日期倒序及 ID 倒序固定排序。结果同时返回活动数据集、修订、总笔数、页数和规范化条件，便于后续报表、CSV、AI 复用。

正式列表与明细排除回收站、其他数据集；标签使用 EXISTS 避免重复行，合并前的标签 ID 仍指向目标。备注修改、清空后以当前内容重新检索。

沿用 B05-r4 的 PC 表格、手机卡片、次要筛选折叠、暖纸主题和现有图标。条件可见可清除；明细、编辑、返回和语言切换保留筛选与页码。空匹配明确区别于请求失败及真实未消费；失败可重试。全局小型语言菜单只切换显示偏好，不重置页面。汇总金额与退款详情按后续依赖任务继续交付。
