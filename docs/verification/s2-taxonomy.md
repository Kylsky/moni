# S2 分类与标签验收（Issue #5）

2026-10-18，本地隔离环境；仅使用合成数据。

## 已完成

- 收入/支出各自维护类目，新增与改名保留历史账目关联、金额和备注；默认名称随界面语言切换，自定义名称保留原文。
- 标签新增与多源合并：明确展示目标名称，重叠关联去重，旧名称作为内部别名指向目标。连续合并会更新旧别名，旧表单再次保存不会重建重复标签。
- 数据集、记录版本和幂等收据控制写入，整批变更原子提交；失败或竞争冲突不会留下半批标签关联。
- PC 双栏与手机类目/标签切换采用批准的 B09-r2 布局及现有素材/图标；支持中英文、主题、键盘焦点、Escape 关闭和失败保留输入。
