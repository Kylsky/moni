# S4 会话管理与故障恢复验收（Issue #14）

2026-10-18。本地真实 D1、每会话真实 SQLite DO、受保护应用接口；故障和模型输出使用可控替身。

## 交付行为

- 会话列表按最近更新排序，支持文字搜索、分页和账本时区的今天／本周／更早分组。首次输入直接生成可识别标题，不额外调用模型；PC 侧栏展示最近会话，手机通过历史入口打开完整列表。没有加入属于扩展草案的微信通道。
- 切换、刷新及另一设备读取服务端消息和真实运行状态。运行中显示忙碌，不排队、不自动加入旧流或重放请求；输入与上下文、运行及草稿权限均以各自会话为边界。
- 删除需本人明确确认并检查活动数据集、版本与唯一操作标识。D1 同一批次写墓碑、清除消息及撤销执行凭据，终止匹配运行；DO 通知失败也无法恢复会话。已入账账目和逐笔备注不受影响，旧 ID 不能重新创建。最少运行与幂等收据保留供核对。
- 明确停止先在受保护业务命令中撤销匹配运行，再取消浏览器读取。旧停止请求重放不能终止新回合。界面分别说明运行、忙碌、取消、中断、超时、失败与上下文上限。
- 读取历史或开始下一轮时核对 DO 当前状态、进程内执行者和 D1 收据／运行／凭据；发现失去执行者时先撤销写入权，再允许明确重试。DO 重启不自动重新调用模型。
- 明确重试只接受同会话最新失败或中止回合，且原用户消息仍为权威历史最后一项。重用该用户消息 ID，生成新的回合及重试关联，不追加同一输入。已有助手或工具结果时保留结果并提示先核对，不丢弃历史重新生成。
- D1 已接纳而 DO 后续保存失败时回读收据；已接纳返回 202，不伪装为未接纳。未知结果保留为失败待核对，不自动发送。模型配置和每次工具执行前检查凭据，写入再次原子检查数据集、会话版本、回合、令牌及截止时间。
- 清理、alarm 和取消按具体回合／令牌执行。旧 alarm、迟到输出或旧数据集收尾不能终止或写入新回合。取消信号是额外保护，数据库撤销仍为最终依据。

## 界面

对照 B04、B17-r2、B18，复用原字标、透明删除助手、Tabler 图标和既有主题令牌。PC 为侧栏加搜索／新对话同排，手机新对话独占一行；删除为 PC 居中弹窗和手机底部弹窗。取消首先获得焦点，支持 Escape，成功后回到正文。

截图 `screenshots/s4-conversations-pc.png`、`s4-conversations-mobile.png`、`s4-conversations-mobile-delete.png` 使用同一合成会话，逻辑视口分别为 1440×1024 和 390×844。现场只核对弹窗并取消；实际删除在隔离浏览器夹具中验收。中英、深浅／系统主题、320px 无横向溢出均通过。未把 UI 位图当产品界面。
