# S4 正式会话与流式持久化验收（Issue #13）

2026-10-18。受保护 Worker、每会话真实本地 DO、真实临时 D1；受控模型和私密指定模型分别验收。

## 已交付行为

- 新增持久会话记录与版本，创建使用活动数据集及操作收据；已存在诊断历史的标识不能被重新认领为正式会话。正式会话地址可刷新、另一个设备可回读。
- 客户端经 TanStack AI 的 useChat / 官方 SSE 传输发送，仅保留当前本人文本、数据集、会话、回合及预期版本；不信任浏览器 assistant/tool 历史，也不发送整本账本。
- DO 在 D1 同一批次核对活动数据集与会话版本、保存服务端生成的用户消息 ID、输入收据及 run 关联后才调用模型；任何接纳失败回滚会话版本且不调用模型。
- 同会话互斥贯穿整个流及必要保存，忙碌不排队。相同已接纳回合返回 202，不重新调用；改变内容重用回合拒绝。SDK 不自动重新加入或重放模型执行，恢复时仍返回真实 activeRun。
- D1 保存完整 SDK 消息、parts 与运行记录；临时上下文不覆盖权威历史。当前采用有界完整上下文（40 条、32 KiB），完整保存另有 1000 条/1 MiB 上限；超限在接纳和模型调用前拒绝，原历史保留。
- 所有执行写入绑定活动数据集、会话版本、回合、令牌及截止时间；过期、删除乃至已移除会话均不能通过诊断路径或旧凭据写回。run 更新还核对具体回合。正式消息和运行写入更新业务修订号，供后续一致备份使用。
- 此阶段正式会话没有账本工具，不查询、修改或正式保存账目。S0 诊断工具继续独立验证，不能写入正式会话。会话列表、删除、明确重试与更完整的中断恢复由 #14 继续交付；财务草稿及查账由 #15–#16 交付。
