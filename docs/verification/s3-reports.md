# S3 收支统计与趋势验收（Issue #12）

2026-10-18。受保护应用接口、本地真实 D1 与合成账目；本阶段统计不调用模型或行情。

## 查询与财务口径

- 列表、统计、分组与趋势复用同一条件编译和精确整数汇总。返回当前活动数据集、版本、具体日期、主币种、笔数及收入/支出/退款/净支出；分页不截断总额。
- 退款按自身发生日参与，类目与标签读取原消费的当前分类；跨月退款可以使当月净支出为负。原消费的历史确认金额与实际退款差额均保留。
- 多币种只加已确认的主币金额；指定 USD 时额外返回原币四项合计。类目和标签分组、每个趋势区间均带可直接传给账目列表的条件。
- 多标签筛选采用 EXISTS，不把一笔账重复计入总额。标签分组本身可以重叠，界面明确不能相加；无标签独立分组。分组明细额外保留“必须有该标签”条件，与已有任选标签筛选相交，避免点开分组后扩大结果。
- 汇总和分组在同一个 D1 批次内读取，核对之前解析时使用的活动数据集及设置版本。金额超过安全整数范围明确拒绝，不返回悄悄舍入后的统计。
- 程序按账本时区确定当天、滚动月份和完整自然月。月底不存在同日时取目标月末；当月截至账本今天，历史月完整。日/周/月趋势按账目日分桶，周一开始，边缘区间裁到当前筛选日期。

## 双端界面

沿用 B08-r3 的四项卡片、橙色支出/黄色退款柱图、支出占比条、单列退款和明细入口；PC 四列、手机两列。月份、实际日期与时区明确展示，额外范围/筛选控件放在可展开区域。精确金额、笔数和区间明细提供 HTML 数据表，颜色不是唯一信息。

筛选、月份和分组保留在路由中，从明细返回仍恢复原报表条件。修改账目、删除恢复后再次进入或刷新统计重新查询正式数据；加载失败隐藏旧图表并保留调整条件与重试。
