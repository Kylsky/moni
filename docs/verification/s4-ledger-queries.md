# S4 自然语言查账与连续追问验收（Issue #16）

2026-10-18。受保护应用接口、本地真实 D1 与每会话 SQLite DO；受控模型与私密真实模型分别验证。

## 行为与边界

- 新增 `query_ledger`，只接受日期区间、消费／收入范围、已有类目和标签、名称／备注关键词、原币、分组和趋势间隔。严格校验结构，不接受 SQL。金额、笔数、类目／标签分组和趋势统一调用现有 `queryReport`，不复制金额计算。
- 程序按账本时区解析日历日期。固定时钟 2026-10-18 时，滚动三个月为 2026-07-18 至 2026-10-18；上个月为上一完整日历月。范围不明确时由助手先澄清。
- 连续追问只能读取同一数据集、同一会话中实际保存的查询工具结果。省略条件保留、显式空值清除；每次查询重新读取当前正式账本。新会话没有可继承条件，不能用前端伪造历史或此前回复的数字替代查询。
- 消费查询包含支出与退款、排除收入。退款按自身日期并沿用原消费类目／标签；关键词继续匹配每笔自己的名称及备注，退款不会冒用原消费备注。指定 USD 同时返回 USD 原币与主币固定折算，金额不混加。
- 结果卡列出日期、时区、实际条件、支出、退款、净支出、笔数、查询时间和同条件明细。类目／标签／趋势表保留明细入口，标签重叠有说明。无匹配显示“未找到记录”，金额用横线，不断言现实中没有消费。
- 原有正式写入规则不变；模型没有确认、记账或任意数据库执行权。查询结果超过 32 KiB 明确拒绝，不静默裁切。工具执行前后检查当前会话执行权和活动数据集。
