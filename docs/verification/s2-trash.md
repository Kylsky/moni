# S2 回收站验收（Issue #7）

2026-10-18；只使用隔离环境与合成账目。

普通删除先显示具体名称、原币金额和日期，确认后进入回收站。正式查询和详情排除已删除记录；回收站可展开查看备注、日期、类目及标签。恢复保留原业务数据，使用当前版本重新进入正式查询。彻底删除仅允许回收站中的对应版本，需再次确认且明确说明无法恢复。

三个命令沿用本人校验、活动数据集、记录版本、幂等收据及原子批处理。删除与编辑、恢复与彻底删除竞争只能有一个成功；数据库失败会保留完整原状态。彻底删除级联清理标签关联。回收站里的标签仍可参与合并，恢复后保留规范化关联。未增加批量清空或自动删除。

双端沿用 B10-r2：PC 居中确认、手机底部确认面板，取消项先获得焦点，Escape 可取消，操作失败保留可重试状态。退款尚未引入，相关删除恢复保护将在退款任务中补齐。
