# S5 筛选 CSV 与完整 JSON 备份验收（Issue #17）

2026-10-18。前置 #15、#16 已完成。只交付导出；文件校验预览和最终整本切换分别由 #18、#19 完成交付。

## 已实现

- 账目列表下载当前筛选的全部正式、未删除记录，忽略浏览器当前页码／每页大小。CSV 直接复用 `entryQuery`、`entrySelect`，因此日期、消费与退款、类目、合并标签、任一／全部标签、名称／备注关键词及无标签条件与账目列表一致；多标签不重复行。
- CSV 使用 UTF-8 BOM、CRLF、逐格双引号并转义内部引号。可能被表格解释为公式的文本及空白／控制字符前缀加单引号。保留独立备注与换行、原币金额、主币金额、类型、发生日、类目标签、退款关联／默认折算／实际覆盖、固定换算来源／比例／报价日和修订号。备注原文完整保存在 JSON，CSV 的前置单引号只用于表格安全。
- 备份是 `format: moni`、`version: 1` 的专用 JSON，含导出时间、修订、账本设置及显式白名单业务字段。覆盖有效与回收站账目、备注、固定换算快照、类目、合并标签及关联、退款关联、完整正式会话消息／工具结果、运行历史、中断和草稿状态。不是数据库 SQL 转储。
- 不读取或导出运行时 Secrets、Access 本人身份、部署配置、DO 状态、执行凭据、幂等收据、请求摘要、协调 metadata、sandbox 标识或 driver epoch。临时报价缓存不作为恢复依据，已确认及草稿的固定快照随业务记录完整保存。S0 探针会话不混入正式会话备份。
- 先在 D1 原子批次读取修订及精确 JSON 行字节／记录总量，再在另一原子批次读取同一活动账本；任何数据集或修订变化返回 409，请使用者重试。导出最多 10 MiB／100,000 条业务记录（包含关联等行），最终文件再次核对大小；超限返回 413，不截断。
- 下载接口沿用本人验证、同源写请求保护、私有不缓存及禁止索引响应；界面校验返回的数据集，拒绝下载旧界面触发的另一活动账本文件。前端下载仅创建短期本地 Blob URL，完成后释放。

## 双端界面

沿用批准 B20 的设置返回、分段黑描边卡片、暖纸／浅面、橙色入口、浅色完整备份按钮及透明小票备份助手。CSV 筛选直接进入既有账目筛选器，避免新增另一套查询规则；账目列表有实际 CSV 下载按钮。完整 JSON 从设置的导出与备份页下载。

## 验证结果

- 最新完整检查通过：格式、类型、401 个中英键、6 项单元、158 项真实本地 D1/DO，另 1 项可选 SDK 能力跳过。生产构建通过；全量 38 项手机／PC 浏览器用例通过。
- 5 项新增接口用例覆盖：CSV 引号／换行／中英文／空备注／公式前缀、分页导出全部匹配、标签去重、USD 固定折算与跨月退款、完整 JSON 的回收站／合并标签／多会话工具历史／草稿、Secrets 与协调凭据白名单排除、真实并发更新与导出的一致修订、超过 10 MiB 的明确拒绝、旧数据集／非法条件／跨站及无身份拒绝。
- 并发用例经公开接口连续修改同一备注 10 次，同时导出 12 次；成功文件的备注、账目版本和全局修订严格对应，竞争只能得到完整快照或 409，最后备注完整。
- 两端浏览器实际下载 CSV 和 JSON 并读取文件：CSV 只含肯德基筛选记录，JSON 的两笔原币／备注内容完整；模拟 413／409 展示可读错误，解除故障后能重试，语言和主题切换正常。测试未配置 AI，模型与报价不可用，导出仍可用。
- 初次测试夹具遗漏删除所需确认、误用标签合并结构、用退款同名定位原消费；按现有接口修正后通过。完整类型检查另发现本地浏览器夹具声明遗漏已有 AI 配置选项，已补齐声明；没有为通过检查放松产品验证。
- 私密输出扫描通过；原有需求、设计、ADR、技能资料未改。此阶段不需要真实模型／汇率请求，未将受控用例当作外部服务验收。
