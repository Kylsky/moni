# S3 固定折算验收（Issue #8）

2026-10-18，本地真实 D1、受保护应用接口及合成账目。

## 行为

- 保留原币最小单位金额及已确认主币金额；手填汇率或实际主币结算额可独立完成，实际结算优先。缺少依据或未核对的金额不能保存。
- 汇率采用原币 → 主币方向。BigInt 有理数计算，中间不经过浮点金额，最后一次半入到主币最小单位；正原币金额舍入后可为零。单笔上下界沿用 S0。
- 采用依据、来源及依据日期固定保存。实际结算保存精确比率供后续按比例退款，展示为实际金额，不把它冒充外部报价。
- 仅改备注、标签或类目沿用原折算；编辑省略币种/日期时保留已有值。金额、日期、币种或依据改变后展示新结果，服务器核对确认金额。换币会清除不适用于新币对的旧输入；改回主币种同样展示并确认新金额。
- PC 表格和手机卡片可查看原币与折合金额；筛选汇总按主币计算，限定原币时另列该币合计，覆盖全部匹配记录，独立于当前分页。超出安全整数范围明确拒绝，可调整筛选；大额及负数小额显示不丢分位。
- 新迁移保留既有账目、回收站、备注、标签关联及合并别名；未改写既有迁移。
