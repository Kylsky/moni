# 多币种按入账时确认的折算金额汇总

Moni 同时保留账目的原币金额、原币种以及确认的汇率、来源、汇率日期和主币种折算金额；首笔正式账目入账后锁定主币种，后续汇率波动不重估历史记录。
这使报表和自然语言查账可复核，同时保留使用者明确提供实际结算金额、或在修改账目时重新确认换算依据的能力。
默认退款沿用原消费币种与汇率，实际主币种退款金额可覆盖默认换算，且退款仍按发生日参与统计。

## Consequences

- 报表反映已确认的记账口径，不代表按当前汇率重新估值的资产余额。
- 默认通过 Frankfurter 明确选用 ECB 来源的历史参考汇率，非报价日取此前最近可用报价；找不到适用报价时需补充换算依据后入账。
- 主币种、原币金额及换算依据均需纳入备份；统计与恢复不能依赖之后仍可获取同一外部报价。
- 默认按原汇率全额退款时应精确冲回原折算金额；实际结算覆盖可能留下差额，首版不单独管理汇兑损益。

## Sources

- [Frankfurter 官方文档](https://frankfurter.dev/)：支持多来源日汇率；实现时应显式选择 ECB，避免将默认混合来源标成 ECB。
- [ECB 参考汇率说明](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)：参考报价的发布频率与信息用途，不保证还原银行卡实际结算。
