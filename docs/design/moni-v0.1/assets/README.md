## 提取方式与使用

使用内置 ImageGen，根据批准的 UI 位图提取、清理并重绘为独立透明背景素材，未使用外部 API Key。交付为 PNG 位图，不是逐像素裁切件或原生 SVG。

各文件具有真实 RGBA 透明通道，纸张主体及道具保留不透明填色。浅色字标使用深色字，深色字标使用暖白字，橙点保留。助手使用同一文件适配深浅主题，原始 PNG 不带页面底色、页面文案、按钮或 UI 面板。

使用时保留原始宽高比。字标建议图片元素宽约 94–118 CSS px；助手在聊天与弹窗中可先以 88–112 CSS px 的图片元素宽度试放，欢迎或权限场景可放大至约 180–240 CSS px。文件包含透明留白，可见主体大小各有差异；manifest 的 slotTargetCssApprox 是目标可见区域，实际布局应结合 visibleBoundsAlpha32 调整，不把整张图片的宽度直接视为主体宽度。

与正文重复表达时插画可作为装饰；字标提供 Moni 的替代文字。真实操作的名称、错误说明和确认信息继续使用界面文字。

## 图标使用现成库

使用项目 package.json 已声明的 @tabler/icons-react，锁文件记录版本 3.46.0。本次没有安装或升级依赖，也没有制作导航、分类、按钮、加载或状态图标的美术文件。

图标统一采用当前主题颜色、约 24 CSS px 和 2px 描边，交互热区至少 44px。饮食、运动、穿搭、统计、设置、上传、下载、删除、搜索等均从该库选取；小票助手手持的道具属于角色插画，不替代功能按钮的图标。

B20 中 CSV、上传和下载的装饰符号也使用图标库，可与已提取的备份助手搭配；不额外制作三套美术图标。背景底色、气泡、边框、按钮、表格、图表和界面文字由 UI 样式与数据渲染。
