## Agent skills

### Issue tracker

Use GitHub Issues. Before reading, creating, or updating tickets,
read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before changing triage labels,
read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. Before exploring the codebase,
read `docs/agents/domain.md`.

### TanStack AI

For AI work, start with `.agents/skills/tanstack-ai/SKILL.md`, then follow
`.agents/skills/ai-core/SKILL.md` and `.agents/skills/ai-persistence/SKILL.md`
for the relevant APIs. These are pinned upstream research snapshots; once SDK
packages are installed, use their version-matched skills and source. Provenance
and the upstream license are in `.agents/upstream/tanstack-ai/`.
